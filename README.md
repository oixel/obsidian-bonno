# Bonno

*A simple theme for Obsidian with a focus on tiny, personal preferences.*

_NOTE:_ While I have left the accent color to be customizable, my personal preference and recommendation is `#F5C35A`!

As of the current moment, Bonno is a dark-mode-focused theme so not a lot exists on the light-mode side of styling. 

To be blunt, is a generally boring and simple color scheme utilizing strictly brownish shades of black, off-whites, and a pastel-mustard yellow for all highlights. While not incredibly-exciting it is clean and visually appealing (at least to me).

## Changes

### Colors

Main accent for everything is this pastel-mustard shade of yellow: `#F5C35A`.
- A darker shade for overlapping / highlighting purposes is still being considered but currently is `#967736`.

#### Backgrounds

Backgrounds consist of a combination of brownish greys:
- `#20201e` (Darker)
- `#292827` (Lighter)
- `#313131` (Greyer)
	- Used primarily for the backgrounds of code blocks and divider borders of UI elements.
	- Significant enough to not be *unnoticeable*, but subtle enough to remain non-distracting.

#### Text

Where white is needed (primarily text), two types of off-white / grey are used:
1. `#DADADA`
	- All text on darker background (`20201e`) (not accented).
	- Borders of code blocks.
2. `#B3B3B3`
	- Text / icons on lighter background (`292827`) (e.g. file explorer).
	- *Note:* this shade is --color-base-70 (darker shade of main white shade).

A lighter shade of grade is used for code block comments: `#969696`.

### Fonts

**UI:** [Necto Mono](https://www.collletttivo.it/typefaces/necto-mono)

**Text:** [iA Writer Quattro S](https://github.com/iaolo/iA-Fonts)

**Monospace:** [CommitMono](https://commitmono.com/).

*NOTE:* Both fonts have been encoded into the theme so that they can be used across devices without having to worry about installation.

### Navigation

- Active file is highlighted with accent color.
  - This turns into an accented border while renaming.

### Miscellaneous

- Bulleted lists now have different symbols based on their level.
  - 1: Filled circle
  - 2: Hollowed circle
  - 3: Filled square
  - 4: Hollowed square

- Internal links between notes no longer have an underline.
- Unresolved links have a dashed underline

- Highlight is solid (full opacity) and matches accent color.

- Code blocks have a slightly lighter background color and a small white border in READ view
